# 🎉 احتفالية عيد ميلاد هديل | Hadel's Royal Birthday Experience

موقع ويب احتفالي تفاعلي فاخر ومبهر صُمم خصيصاً للاحتفال بعيد ميلاد الأخت الغالية **هديل (Hadel)**، مليء بالمؤثرات البصرية والصوتية الراقية، ومعرض للذكريات التفاعلي، ورسالة أخوية ملكية بختم الشمع، وتورتة تفاعلية لإطفاء الشموع، وصندوق هدايا ومفاجآت ثلاثي الأبعاد.

---

## 🌟 الميزات التفاعلية الرئيسية (Features)

1. **الواجهة الرئيسية والترحيب الملكي (Celebratory Hero Section):**
   - تايبوجرافي عربي فخم باسم "هديل" وتهنئة خاصة.
   - بالونات تفاعلية ثلاثية الأبعاد تطفو وتستجيب للنقر واللمس.
   - خلفية بريق النجوم المتحركة (Interactive Stardust Particles).

2. **مشغل الموسيقى الملكي التفاعلي (Floating Audio Player):**
   - نغمات وموسيقى عيد ميلاد مبنية عبر **Web Audio API** لتعمل فوراً دون تأخير وبجودة نقية.
   - تحكم كامل بمستوى الصوت، زر كتم، ومؤشر موجات صوتية نابض بتصميم زجاجي عائم.

3. **ممر الذكريات ومعرض الصور (Interactive Memory Lane):**
   - عرض متجاوب لكافة الصور الثمانية مع الحفاظ التام على أبعادها وجودتها الأصلية.
   - بطاقات تفاعلية مع تأثير إمالة ثلاثي الأبعاد (3D Perspective Tilt).
   - انطلاق قلوب تفاعلية (Heart Reaction Bursts) عند التفاعل مع أي صورة.
   - عارض صور سينمائي بملء الشاشة (Fullscreen Lightbox) يدعم التكبير والسحب باللمس على الهواتف.

4. **تورتة عيد الميلاد الافتراضية (Virtual Birthday Cake):**
   - تصميم تورتة فاخرة متعددة الطبقات مع شمعة بلهب متذبذب وواقعي.
   - إمكانية إطفاء الشمعة افتراضياً بالنقر أو النفخ، مع ظهور مسار دخان ناعم.
   - إطلاق فوري لمدافع القصاصات (Confetti Cannons)، ومؤثرات تصفيق صوتية حية.
   - نافذة تفاعلية لكتابة وتمني أمنية (Make a Wish Modal).

5. **رسالة الأخ الملكية بختم الشمع (Brother's Wax-Sealed Letter):**
   - ظرف ملكي ثلاثي الأبعاد محكم بختم شمعي أحمر يحمل حرف "هـ".
   - عند النقر، ينكسر الختم ويفتح الظرف بسلاسة لتنزلق بطاقة المعايدة الدافئة المكتوبة من القلب.

6. **صندوق الهدية وشهادة التقدير (Gift Box & Keepsake Certificate):**
   - صندوق هدايا ثلاثي الأبعاد يُفتح بحركة شريط ذهبي احتفالية.
   - شهادة تذكارية مخصصة لأفضل أخت في العالم قابلة للعرض والمشاركة.
   - كروت تفاعلية تسرد أجمل خصال ومشاعر الأخوة، وعدادات الذكريات.

7. **شريط التنقل السريع العائم (Quick Navigation Bar):**
   - شريط تحكم زجاجي مريح في أسفل الشاشة للقفز السلس بين أقسام الموقع على الهواتف والكمبيوتر.

## 🚀 كيفية تشغيل المشروع وتجربته محلياً (How to Run)

### 1. المتطلبات:
- وجود بيئة **Node.js** (إصدار 18 أو أحدث).

### 2. تثبيت الحزم (إذا لم تكن مثبتة):
```bash
npm install
```

### 3. تشغيل خادم التطوير للتجربة المباشرة:
```bash
npm run dev
```
سيظهر لك رابط محلي في شاشة الأوامر (غالباً: `http://localhost:5173`)، افتحه في المتصفح على الكمبيوتر أو من هاتفك لتجربة الموقع مباشرة بكافة تفاعلاته وموسيقاه!

### 4. تجربة النسخة الإنتاجية المبنية (Preview Production Build):
```bash
npm run build
npm run preview
```

### 5. تشغيل حزمة الاختبارات الآلية (124 اختبار):
```bash
npm run test
```

## 📦 كيفية رفع المشروع على GitHub / Git (Git Push Guide)

المشروع يحتوي بالفعل على ملف `.gitignore` احترافي ومضبوط، ويستثني تلقائياً المجلدات الثقيلة غير الضرورية مثل `node_modules` و `dist`.

لتهيئة ورفع المشروع لأول مرة على مستودعك:

```bash
# 1. تهيئة مستودع Git محلياً
git init

# 2. إضافة كافة الملفات المعتمدة (الملفات البرمجية والصور)
git add .

# 3. حفظ التغييرات (Commit)
git commit -m "feat: complete luxury interactive birthday web app for sister Hadel"

# 4. تغيير اسم الفرع الرئيسي إلى main
git branch -M main

# 5. ربط المستودع برابط مستودعك على GitHub (استبدل الرابط برابطك)
git remote add origin https://github.com/USERNAME/REPO_NAME.git

# 6. الرفع إلى GitHub
git push -u origin main
```

## 🌐 ما الملفات التي يتم رفعها؟ (Files to Commit)

بفضل ملف `.gitignore`:
- ✅ **الملفات التي يتم رفعها تلقائياً:**
  - كل ملفات الكود في مجلد `src/` (المكونات، الأنيميشن، الصوت، الواجهات).
  - ملفات الإعدادات (`package.json`, `tailwind.config.js`, `vite.config.ts`, `tsconfig.json`).
  - كافة الصور الـ 8 في المجلد الرئيسي وفي `public/photos/`.
  - ملفات التوثيق و `index.html`.
- ❌ **الملفات المستثناة تلقائياً (لا تُرفع):**
  - مجلد `node_modules/` (لأنه يتم تثبيته عبر `npm install`).
  - مجلد `dist/` (لأنه ينتج تلقائياً عند تشغيل `npm run build`).
  - ملفات الكاش المؤقتة وملفات النظام.
